# Release 0.0.22 / 发布 0.0.22

## 中文

- 发布 `calcit-fetch` 0.0.22，要求 Calcit 0.13.64。
- 保持共享 `calcit_native_ffi 0.1.3`、C-safe async ABI 与既有请求/回调语义不变。
- 延续 0.0.21 已记录的边界：blocking request 暂无 native cancel hook。

## English

- Release `calcit-fetch` 0.0.22 with Calcit 0.13.64 required.
- Keep shared `calcit_native_ffi 0.1.3`, the C-safe async ABI, and existing request/callback semantics unchanged.
- Preserve the documented 0.0.21 boundary that blocking requests do not yet expose a native cancel hook.
