# Align Fetch release-candidate FFI evidence

## 中文

- 将 Fetch 的 Calcit 工具链声明从 0.13.76 对齐到 0.13.77。
- 将 Linux CI 的 Interface IR guard 更新为 0.13.77 的稳定专用诊断：开放 Dynamic、callback 与宿主管理的 `FfiTask`。
- 将 `setup-calcit` 固定到 v1.4.0 对应的不可变 commit；不修改 Fetch API、FFI lowering、ABI 或运行时行为。

## English

- Align Fetch's declared Calcit toolchain from 0.13.76 to 0.13.77.
- Update the Linux CI Interface IR guard to the stable 0.13.77 diagnostics for open Dynamic, callback, and host-managed `FfiTask` boundaries.
- Pin `setup-calcit` to the immutable commit behind v1.4.0; Fetch API, FFI lowering, ABI, and runtime behavior remain unchanged.
