# Calcit 0.13.64 upgrade / 升级记录

## 中文

- 将模块要求的 Calcit 版本从 0.13.60 升级到 0.13.64。
- 使用新版 formatter 将 Snapshot namespace/definition key 规范化为 symbol，读取仍兼容旧 string key。
- 保持 `calcit_native_ffi 0.1.3` 与现有有界异步 backpressure 协议不变；由 Rust callback/complete 回归、C-safe export 检查和 Calcit 模块入口共同验证。

## English

- Upgrade the module's required Calcit version from 0.13.60 to 0.13.64.
- Canonicalize Snapshot namespace/definition keys to symbols with the new formatter while retaining legacy string-key read compatibility.
- Keep `calcit_native_ffi 0.1.3` and the existing bounded async backpressure protocol unchanged; verify it with Rust callback/completion regressions, C-safe export checks, and the Calcit module entry.
