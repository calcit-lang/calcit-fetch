# 发布 0.0.19 / Release 0.0.19

## 中文

- 发布基于稳定 `calcit_native_ffi 0.1.3` 的有 deadline 异步结果投递。
- host queue 持续饱和时不再无限占住 fetch worker。

## English

- Release deadline-aware async result delivery based on stable `calcit_native_ffi 0.1.3`.
- Prevent a persistently saturated host queue from retaining a fetch worker indefinitely.
