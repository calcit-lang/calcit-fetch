# Upgrade calcit-fetch to Calcit 0.13.77 / 将 calcit-fetch 升级到 Calcit 0.13.77

## 中文

- 将 `deps.cirru` 中的 Calcit 工具链基线从 0.13.76 对齐到 0.13.77。
- 将 Interface IR 门禁更新为 0.13.77 的精确诊断码，同时保持原有三个 unsupported path 与 native async lowering 断言不变。
- 使用仓库既有 nightly Rust、C-safe async FFI、取消、文档、示例与 Interface IR 门禁验证升级。
- 保持 calcit-fetch 0.0.24、HTTP 行为、typed `FfiTask` / Result callback 契约、native ABI 与依赖版本不变。

## English

- Align the Calcit toolchain baseline in `deps.cirru` from 0.13.76 to 0.13.77.
- Update the Interface IR gate to Calcit 0.13.77's precise diagnostic codes while preserving the same three unsupported paths and native async lowering assertions.
- Validate the upgrade with the repository's existing nightly Rust, C-safe async FFI, cancellation, docs, examples, and Interface IR gates.
- Keep calcit-fetch 0.0.24, HTTP behavior, typed `FfiTask` / Result callback contracts, native ABI, and dependency versions unchanged.
